title: Keyboard Shortcuts
---

Shortcuts work while the 3D view or any Click to Build window has the keyboard, and are ignored while you type in a field. Esc is the exception: Studio keeps it for itself inside plugin windows, so click the 3D view first, or use **Clear & Cancel**.

-   Cancel building: Esc
-   Pause / resume building: Shift+P (keeps your points, hands the mouse back to Studio)
-   Start/Stop Structure Builder: Shift+F
-   Start/Stop Model Placer: Shift+R
-   Start/Stop Shape Builder: Shift+T
-   Lock current plane: Shift+V
-   Disable grid snap: Hold Shift
-   Precision while disabled: Hold Shift+Option (rounds movement to 0.1)
-   Close loop for polygon: Space
-   Edit Mode (Polygon, Curve, Line, Pipe, Truss): Shift+G

-   Undo: Ctrl+Z / ⌘Z
-   Redo: Ctrl+Y / Shift+⌘Z
