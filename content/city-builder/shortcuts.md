title: Keyboard shortcuts
sidebar_position: 10
description: Every key the road, rail and polygon tools answer to.
---

A running tool shows its keys on a card in the corner of the viewport. **Show shortcuts panel** under Advanced settings hides the card. The keys work either way.

## Roads: Draw

| Key | Action |
| --- | --- |
| **C** | Switch between straight and curved roads. |
| Hold the mouse button | Lay this one road the other way, curved or straight. |
| Drag | Bend this road. |
| **Shift** | Use the road type under the cursor. |
| **Z** / **X** | Lower or raise the next road by one level. |
| **Esc** | End the chain, then stop the road builder. |

## Roads: Edit

| Key | Action |
| --- | --- |
| **Shift** | Set an island's width all along its road. |
| **Esc** | Cancel the drag, then stop the road builder. |

## Roads: Roadside

| Key | Action |
| --- | --- |
| **Shift** | Add to the pick, or let go of a picked stretch. |
| **Delete** / **Backspace** | Set the picked stretches' race items back. |
| **Esc** | Cancel the drag, let go of the pick, then stop the road builder. |

## Roads: Junctions

| Key | Action |
| --- | --- |
| **X** / **R** | Turn the junction 5 degrees forward. |
| **Z** / **Shift+R** | Turn the junction 5 degrees back. |
| **Esc** | Stop the road builder. |

## Rails

| Key | Action |
| --- | --- |
| **C** | Switch between straight and curved tracks. |
| **Z** / **X** | Lower or raise the next track. |
| **Esc** | End the chain, then stop the rail builder. |

## Polygon buildings

| Key | Action |
| --- | --- |
| **Enter** / **Space** | Build the outline. |
| **Backspace** | Take back the last corner. |
| **Esc** | Clear the outline. |

## Everywhere

**Ctrl+Z** and **Ctrl+Y** undo and redo. Every edit the plugin makes is one step.
